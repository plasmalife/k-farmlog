# K영농일지

사진·음성·메모를 날짜와 재배지별 일기로 정리하는 한국어 웹앱입니다. Next.js, Supabase, OpenAI API를 사용합니다.

## 현재 구현 (2026-10-01)

- reference/메인화면구성.pptx: 위쪽 자료 링크 → 제목/인사말/사진찍기 → 중앙 친구소식 → 음성·글 기록 버튼.
- reference/친구소식.pptx: 사진·글이 이어지는 게시판. 홈과 친구소식이 같은 데이터 사용. 작성 시각의 경과 시간만 표시하고 작성자 이름은 표시하지 않음. 실제 게시물과 구분된 참고 샘플 제공.
- reference/오늘의일기.pptx: 날짜, 지역/작물, 사진 3개, 오늘의 작업내용, 사진 분석·메모, 음성 요약·키워드.
- 체험 모드와 임시 메모리 저장 제거. 저장 연결이 없으면 저장 성공으로 표시하지 않음.
- 사진은 촬영/다중 업로드 후 최대 3장 미리보기. 저장 전 삭제·재선택, 저장 후 개별 삭제 가능. 날짜·재배지별 3장 제한. 자동 교체 대신 사용자가 삭제 후 추가.
- 모든 사진의 글자를 읽고 비료 성분·숫자·단위·수식을 보존하도록 요청. 작물 상태 관찰은 첫 사진 한 장만 수행. AI 조언은 관찰 사실과 구분하며 확진·농약 처방을 하지 않음.
- 녹음 종료 후 STT 원문을 편집 가능한 메모로 표시. 일기에는 요약·키워드만 저장. 음성 파일은 서버 파일 저장소에 보관하지 않음. 사진 기록의 직접 입력 메모는 보존하고 별도 음성 메모는 요약함.
- 게시물은 명시적인 공개 버튼으로 글과 사진 최대 3장을 공개. 공개 게시물은 비회원도 읽을 수 있음. 작성·삭제는 로그인 세션 필요, 다른 사용자의 글은 수정/삭제 불가. 개인 노트와 사진은 비공개.
- 자료 링크: 농사자료는 https://rifamhomepage.pages.dev/ , 농업뉴스·비료/병해충은 기존 공식 자료 링크.

## Supabase

전용 프로젝트: cjalujpyghyvyuiqpgdk / 서울 / 조직 ripbngiqlzogvmudnjwa.
supabase/migrations의 SQL을 순서대로 적용합니다. 현재 운영 프로젝트에는 적용 완료했습니다.
Authentication → Sign In / Providers → Anonymous Sign-Ins를 활성화해야 전화번호 입력 가입이 동작합니다.

전화번호 입력은 본인 인증이 아닙니다. 이 브라우저의 익명 Auth 세션에 회원정보를 연결합니다. 다른 기기에서 같은 번호로 기존 기록에 로그인하지 않습니다. 브라우저 데이터 삭제/로그아웃 후 복구는 미지원이며 앱 안에 안내합니다. OTP와 계정 복구는 후속 작업입니다.

모든 개인 테이블에 소유자 RLS 적용. farm-photos는 비공개입니다. community-photos도 비공개 버킷이며, 게시물에 연결된 사진만 공개 읽기 정책으로 서명 URL을 발급합니다. 사용자에게 관리자 키를 노출하지 않습니다.

## Vercel 환경변수

| 이름 | 용도 |
|---|---|
| NEXT_PUBLIC_SUPABASE_URL | Supabase URL |
| NEXT_PUBLIC_SUPABASE_ANON_KEY | 공개 publishable key |
| OPENAI_API_KEY | 서버 전용 OpenAI 비밀키 |
| OPENAI_VISION_MODEL | 기본 gpt-4.1-mini |
| OPENAI_TRANSCRIBE_MODEL | 기본 gpt-4o-mini-transcribe |
| SUPABASE_SERVICE_ROLE_KEY | 서버 전용 365일 사진 정리 |
| CRON_SECRET | 예약 정리 API 인증 |

NEXT_PUBLIC 값은 빌드 때 반영됩니다. Production 환경변수 설정 후 재배포가 필요합니다.
OPENAI_KEY_API는 이 앱에서 사용하는 이름이 아닙니다.

Playwright는 별도 실행 중인 서버가 필요합니다. 기본 http://127.0.0.1:3000 또는 TEST_BASE_URL을 사용합니다.

실제 OpenAI 합성 비료 사진 OCR(21-17-17, 2kg, 10a), 합성 한국어 음성 인식은 별도로 성공했습니다.

## 남은 운영 설정과 한계

- 마지막 확인에서 Supabase anonymous_users=false. 활성화 후 실제 회원가입 → 사진/음성 기록 → 다른 세션 접근 제한을 검증해야 합니다.
- CRON_SECRET와 SUPABASE_SERVICE_ROLE_KEY 미등록. 365일 정리 코드/예약은 있으나 아직 자동 정리되지 않습니다.
- JPEG/PNG/WEBP 입력, 1600px JPEG 압축, HEIC 미지원. 녹음 최대 3분.
- 사용자당 24시간 AI 요청 40회, 전체 300회. STT, 각 사진 OCR, 메모 정리는 각각 한도에 포함됩니다. 실패 요청도 소비합니다.
- AI 정리에 실패하면 모달에 입력을 유지하고 재시도합니다. 창을 닫으면 저장 전 초안은 사라집니다. 오프라인 캐시는 없습니다.
- 파일 저장과 DB 저장은 원자적 트랜잭션이 아닙니다. 같은 모달 재시도 시 고정 entry ID/사진 슬롯을 사용합니다. 파일 저장 후 DB 오류가 나면 재시도가 필요합니다. 여러 탭에서 같은 슬롯에 동시에 쓰면 마지막 쓰기가 남을 수 있습니다.
- 게시물은 20개씩 더 보기, 최신 소식은 1분마다 새로 읽습니다. 댓글·공감·이웃 추가 기능은 포함하지 않습니다.
- 실제 기기의 카메라/마이크 권한과 로그인 후 실제 전체 저장 흐름은 추가 검증이 필요합니다.
