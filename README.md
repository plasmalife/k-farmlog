# K영농일지

사진과 목소리로 영농 작업을 기록하는 한국어 모바일 웹앱입니다. Next.js App Router, Supabase PostgreSQL/Storage/Auth, OpenAI API를 사용합니다.

## 실행

```sh
npm ci
cp .env.example .env.local
npm run dev
```

Supabase 공개 환경변수가 없으면 **체험 모드**입니다. 체험 기록은 메모리에만 있으며 새로고침 시 초기화됩니다. AI 응답을 흉내 내지 않습니다.

## Supabase 최초 설정

1. 지정 조직 `ripbngiqlzogvmudnjwa`에서 이 앱 전용 프로젝트를 생성합니다. 가능하면 Seoul 리전을 선택합니다.
2. SQL Editor에서 `supabase/migrations/001_initial.sql`을 실행합니다. 최초 빈 프로젝트용 마이그레이션입니다. 기존 데이터가 있는 프로젝트에는 검토 없이 실행하지 마세요.
3. Authentication → Providers/Sign In에서 **Anonymous sign-ins**를 켭니다. 전화번호 OTP는 베타에서 사용하지 않습니다.
4. 프로젝트 URL과 publishable/anon key를 Vercel 환경변수에 넣습니다.
5. 실제 사용자와 다른 두 세션으로 RLS 격리, 이미지 signed URL, CRUD를 검증합니다. 키 미연결 상태에서는 실제 DB 검증 완료로 간주하지 않습니다.

## Vercel 환경변수

| 이름 | 용도 | 공개 가능 여부 |
|---|---|---|
| NEXT_PUBLIC_SUPABASE_URL | Supabase 프로젝트 URL | 공개 설정 |
| NEXT_PUBLIC_SUPABASE_ANON_KEY | publishable 또는 legacy anon key | 공개 설정, RLS 필수 |
| OPENAI_API_KEY | 사진 분석·음성 변환 | 비밀, 서버만 |
| OPENAI_VISION_MODEL | 기본 gpt-4.1-mini | 모델명 |
| OPENAI_TRANSCRIBE_MODEL | 기본 gpt-4o-mini-transcribe | 모델명 |
| SUPABASE_SERVICE_ROLE_KEY | 사진 보관기한 만료 정리 | 비밀, 서버만 |
| CRON_SECRET | 예약 정리 API 보호용 무작위 비밀값 | 비밀, 서버만 |

환경변수를 Production/Preview 중 사용할 환경에 등록한 후 다시 배포합니다. `NEXT_PUBLIC_*` 값은 빌드 시 반영됩니다. 비밀값을 GitHub나 대화에 올리지 않습니다. `.env.local`은 Git 제외 대상입니다.

## 베타 동작

- 전화번호 입력 후 익명 Auth 사용자 세션에 회원 정보를 연결합니다. 전화번호만으로 다른 기기의 기존 계정을 조회하지 않습니다. 브라우저 데이터를 지우거나 로그아웃하면 접근을 잃을 수 있어 UI에서 안내합니다. 본인 인증·계정 복구는 후속 버전입니다.
- 지역/작물/재배지를 등록하고 **KST 날짜 + 재배지**로 노트를 묶습니다. 하루는 00:00~23:59:59 KST입니다. 요청 후 24시간 지연하는 방식이 아닌 즉시 정리입니다.
- 사진 → 작업 메모 → 음성 핵심 기록 → 사진 추출 내용 순서입니다.
- 음성 파일은 메모리에서 API로 전송하고 변환 후 앱 저장소에 보관하지 않습니다. 실패 시 모달이 열려 있는 동안 재시도할 수 있습니다. OpenAI 측 보관 정책은 앱의 저장 정책과 별도입니다.
- 비료·농약 이름, 양과 단위를 요약에 보존하도록 지시하고 저장 전 사용자가 확인합니다. AI 정확도를 보증하지 않습니다.
- 사진은 날짜·재배지별 고정 슬롯 3개만 저장합니다. 모든 분석 결과 텍스트는 남습니다. 흐린 사진은 저장하지 않고, 주요 변화가 없으면 기존 사진을 우선합니다. 비교는 기존 관찰 설명을 활용하는 MVP 방식입니다.
- 사진 자동 점수는 휴리스틱입니다. 대표 사진은 고정할 수 있습니다. 사진을 삭제하려면 운영자가 해당 파일과 메타데이터를 함께 삭제합니다(사용자 사진 개별 삭제는 후속).
- 녹음은 최대 3분, 사진은 JPEG/PNG/WEBP 입력 후 1600px JPEG 압축. HEIC 입력은 현재 미지원입니다.
- AI 비용 보호: 사용자당 최근 24시간 40회, 전체 300회. 실패한 호출도 한도를 소비합니다.
- 친구 소식은 사용자가 명시적으로 올린 텍스트만 로그인 사용자에게 공개합니다. 비공개 노트는 자동 공유하지 않습니다. 댓글·좋아요·사진 공유는 후속입니다.
- 농업뉴스/병해충 자료는 공식 사이트 링크입니다. 가짜 기사, 예보, 병해충 확진 결과를 만들지 않습니다.
- 오프라인 임시 저장, 음성 원본 보관, 자동 백업은 보완 문서에 따라 구현하지 않았습니다.

## 365일 사진 정리

Vercel Cron이 매일 18:15 UTC에 `/api/cleanup`을 호출합니다. `CRON_SECRET` 및 service role 환경변수 설정이 필요합니다. 파일 삭제 성공 후 사진 메타데이터를 삭제하며 텍스트 노트는 남깁니다. Cron 미설정 시 365일 자동 삭제는 작동하지 않습니다. 기본 배치 1,000개입니다. DB 백업에 Storage 파일 백업이 포함된다고 가정하지 않습니다.

## 알려진 베타 한계

- 동시 여러 기기에서 같은 사진 슬롯 교체 시 마지막 쓰기가 반영됩니다. 익명 세션 베타를 위한 단순 구현입니다.
- AI 처리는 요청 단위입니다. 내구성 있는 백그라운드 큐는 아직 없으며 처리 중 화면을 닫으면 재시도가 필요할 수 있습니다.
- 사진과 메타데이터는 서로 다른 저장 서비스이므로 원자적 트랜잭션이 아닙니다. UI는 저장 실패를 알려 주며 텍스트 저장은 유지됩니다. 운영 전 실패 주입 테스트 및 정리 작업 보강을 권합니다.
- 휴대전화 번호만 사용한 로그인은 본인 인증이 아닙니다. 공개 정식 서비스에는 OTP 및 계정 복구, 개인정보 담당자/문의처, 탈퇴 흐름이 필요합니다.
